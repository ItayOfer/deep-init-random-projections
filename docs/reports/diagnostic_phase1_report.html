Diagnostic Phase 1 — Hypothesis Tests

7 short runs on the cluster. Source: reports/results/diagnostic_phase1.json · log: fnn_diag_p1-165867.out

How to read this report.
  • What "30 epochs / 10 epochs" means. 6 of the 7 runs (#1–#6) were trained for 30 epochs — short enough to be cheap, long enough to see whether the run trains, stalls, or collapses. Run #7 (cifar10/100L/NoBN) was capped at 10 epochs on purpose: we only needed to confirm gradient death, which happens within the first 3 epochs, so a longer run would have been wasted compute.
  • Primary metric throughout the report: eval_train_accuracy — accuracy on the full training set evaluated in a clean forward pass (model in eval() mode, BN using running stats, no dropout). This is the same metric used in the thesis pass criterion (eval_train_accuracy ≥ 0.995 and eval_train_loss ≤ 0.10). "Best" = peak across all epochs. "Final" = value at the last epoch.
  • LR column added below so the "cosine decayed too fast" claim is directly visible: every cosine run has LR ≈ 0 by epoch 30.

Key Findings

1. The fmnist/50L/NoBN crash is solved. Constant SGD at lr=0.003 reaches 95.67% with monotonic improvement, no collapse, gradients healthy (min~0.09, max~2.4 across layers). The OneCycle LR ramp-up to 0.01 was the destabilizing factor, exactly as hypothesized.
2. Slower BN momentum (0.01) looks promising for fmnist/50L/BN. At epoch 30, this configuration is at 96.68% — higher than the original ever reached. Critically, the BN running variance is growing slowly (1.77 → 2.29) without runaway. But the original collapse happened at epoch 43, so we MUST extend this to 60-100 epochs to know if the fix holds.
3. cifar10/50L/BN is ambiguous. The slow-BN variant reached the same 0.54 as the original at the same point in training. We can't yet tell if it will collapse like the original — needs a longer run. Lowering LR further (0.0003) hurts learning too much.
4. cifar10/100L/NoBN is a clean negative result. Gradient norms drop from ~10⁻³ to literally 0.0 within 3 epochs. He init absolutely cannot support 100L FC depth without normalization. This belongs in the thesis as a finding.
5. Cosine annealing over 30 epochs is misleading. See Figure 2 and the LR ep1 → epN column: every cosine run decays from its starting LR down to ≈ 10⁻⁵–10⁻⁶ by epoch 30, so the last ~5 epochs do essentially zero learning. The cosine variants (#1, #3, #4, #5) plateau at least partly because they ran out of LR budget, not because they truly converged or stabilized. For 30-epoch diagnostics, prefer constant LR or warmup-then-flat; reserve cosine for full-length runs where its T_max matches.

Recommended Phase 2 (revised)

Goal. Confirm Phase 1 winners under longer training (100 epochs), resolve the cifar10/50L/BN ambiguity with a constant-vs-adaptive A/B test, and add symmetric gradient-death coverage for fmnist/100L/NoBN.

LR-schedule choice

Phase 1's "cosine decayed too fast" issue was not a problem with cosine itself — it was a mismatch between T_max (30) and the actual epoch budget. For Phase 2 (100 epochs), cosine with T_max=100 is the correct, reproducible schedule for the runs we expect to train smoothly.

For the one ambiguous architecture — cifar10/50L/BN — we add a constant-vs-plateau A/B test. ReduceLROnPlateau (patience=5, factor=0.5, monitor eval_train_loss) is informative here: if the run collapses, we expect to see the LR drop just before / during the collapse; if the run climbs cleanly, we'll see no LR drops at all. Either outcome is a clear signal.
