Diagnostic Phase 2 — Long-Run Confirmation + Adaptive LR A/B

7 runs on the cluster (job fnn_diag_p2-165881, dgx02). Source: reports/results/diagnostic_phase2.json · log: fnn_diag_p2-165881.out

Headline. The advisor's intuition was right: adaptive learning rate (ReduceLROnPlateau) rescues the cifar10/50L/BN architecture from a guaranteed BN-driven collapse (0.13 final with constant LR) to a clean climb (0.9577 final). At the same time, Phase 2 revealed that Phase 1's "promising" fmnist/50L/BN result was an artifact: with cosine matched to the full 100 epochs, that run also collapses catastrophically at epoch 31.
How to read this report.
  • Primary metric: eval_train_accuracy on the full training set in model.eval(). Thesis pass criterion: ≥ 0.995 AND eval_train_loss ≤ 0.10.
  • Run lengths. 6 of 7 runs trained 100 epochs; run G is a 10-epoch gradient-death symmetry check (mirror of Phase 1 run #7).
  • Key new column: BN var (final) — the mean of BN running variances across all 50/100 layers at the last epoch. Values above ~10 indicate runaway BN drift, the mechanism behind the collapse.

Key Findings

1. Adaptive LR is the right schedule for the collapse-prone BN architectures. Run D climbed cleanly to 0.9577 with 4 plateau-triggered LR drops, while the same architecture with constant LR (C) collapsed at epoch 71 (final loss=173 at peak instability, bn_var=158). The advisor's hypothesis is now well-supported by data: adaptive LR throttling prevents the BN-running-variance runaway that drives the collapse.
2. Phase 1's "promising" fmnist/50L/BN was a measurement artifact. Phase 1 used cosine with T_max=30, so by epoch ~25 the LR was already near zero — effectively freezing the model before BN drift could compound. Phase 2 used T_max=100, exposing the real dynamics: a clean climb to 0.9 by ep 21, then a catastrophic loss spike (ep 31: loss=18.2) and total collapse. This validates the original Phase 0 sweep failure for this architecture and underscores why scheduler choice must match epoch budget.
3. The collapse mechanism is BN-variance runaway, not LR overshoot. Run C used constant LR=1e-3 throughout (no scheduler at all) and still collapsed — bn_var grew from ~1 to ~158 by the end. This rules out the "LR too high → diverges → recovers" hypothesis and points squarely at compound BN updates: at depth 50, small drift in running statistics per epoch accumulates over tens of epochs into a regime where the forward pass at eval time produces non-finite or extreme activations.
4. The Phase 1 winner (A: fmnist/50L/NoBN const SGD) did not cross the 0.995 threshold even at 100 epochs. Best was 0.9856 at epoch 50; the run showed mild instability (drop to 0.80 at ep 71, recovery to 0.98 by ep 91). Final loss (0.0587) is well under the 0.10 threshold, but accuracy falls 0.94 percentage points short. This suggests either: more epochs may not help (the model has converged to a different minimum), or we need a different optimizer/regularizer to push past.
5. 100L/BN is borderline-untrainable with He init. Both E (cifar10) and F (fmnist) stayed near 0.20 best accuracy across 100 epochs. They don't suffer gradient death like 100L/NoBN, but they don't learn meaningfully either. The BN buys some signal but not enough. This is a second negative result for the thesis: He init at depth 100 is insufficient even with BatchNorm.
6. fmnist/100L/NoBN is dead, mirroring cifar10/100L/NoBN. Run G confirmed in 10 epochs what we expected: gradients drop to exactly 0 by epoch 3, training never moves. Both 100L/NoBN runs are now symmetric negative results. Thesis sentence: "He-init FC networks at depth 100 without normalization cannot be trained; gradients vanish to machine zero within three epochs, regardless of dataset."

Negative results to formalise in the thesis:
  1. 100L/NoBN is unconditionally dead with He init. Confirmed on both fmnist (run G) and cifar10 (Phase 1 run #7). Gradients vanish to exact zero within 3 epochs.
  2. 100L/BN is borderline-untrainable with He init. Both fmnist and cifar10 stall at ~0.20 accuracy across 100 epochs. BN buys signal but not enough at depth 100.
  3. 50L/BN requires adaptive LR to avoid catastrophic BN-statistic runaway. Both cosine and constant LR cause collapse; only ReduceLROnPlateau (with sufficient patience to detect a plateau before BN runs away) trains successfully.
